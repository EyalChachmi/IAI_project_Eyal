# React Frontend

## Installation

```bash
cd frontend
npm install
```

## Running the Application

```bash
npm start
```

The application will start on `http://localhost:3000`

## Features

- **User List Display**: Shows all users in a card-based layout
- **Search by ID**: Filter users by their ID using the search bar
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Real-time Updates**: Fetches data from the Flask backend API

## Usage

1. Make sure the Flask backend is running on `http://localhost:5000`
2. Start the React application
3. View the list of users
4. Use the search bar to filter users by ID
5. Click "Show All Users" to clear the search filter

## Technologies Used

- React 18
- Axios for API calls
- CSS3 for styling
- Responsive grid layout
